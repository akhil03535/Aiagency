# database/

This folder holds database-related artifacts that live outside the Prisma schema itself:

- ER diagrams (exported as images/mermaid once the schema stabilizes)
- Manual SQL snippets for one-off maintenance (data backfills, index tuning)
- Seed data exports for staging/demo environments

The **source of truth** for the schema is always `server/prisma/schema.prisma`.
Migrations live in `server/prisma/migrations/` and are generated by Prisma —
never hand-edit files in that folder.

Populated starting Phase 2 (Database + Authentication) once real migrations exist.
